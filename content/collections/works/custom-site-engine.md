## 为什么要自己造一个引擎？

市面上的静态博客工具（Astro、Hexo、Hugo 等）往往把内容散落在前端代码目录中，非专业前端改一下页面布局或个人简介都要翻好几个模板文件；而传统带数据库后台的博客又太重，还需要维护服务器。

于是我基于 Node.js 原生能力，只引入 3 个核心解析包，写了一套 **本地可视化工作台 + 纯静态构建输出** 的自研架构，它的特点是：

1. **内容与代码彻底隔离**：所有配置与文章都在 `content/` 目录下，格式只有 `JSON` 和纯 `Markdown`。
2. **不绑定固定博客场景**：支持自由新建任意内容合集（作品、笔记、书单、实验室），首页与页面采用积木块（Hero / Bento / Feed / Timeline / Markdown）自由拼装。
3. **内置本地 Studio（`/studio`）**：无需命令行改配置，打开浏览器即可换风格皮肤、改强调色、拖拽导航、分栏写 Markdown 并直接 `Ctrl+V` 贴图。
4. **0 运行时静态输出**：构建结果 `dist/` 不含任何后台代码或前端重型框架 JS，打开即秒开。
